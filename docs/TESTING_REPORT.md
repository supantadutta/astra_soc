# Testing Report

This report is a truthful account of what was actually executed in the build
environment. Reproduce with `make test` (backend) and `make test-e2e` (browser).

## Environment

- Python 3.11.15, Node 22, Docker 29, on Linux.
- Backend DB for tests: temporary SQLite (see `apps/api/tests/conftest.py`).
- Browser: pre-installed Chromium via Playwright.

## End-to-end tests (Playwright)

Command: `cd apps/web && npx playwright test --project=chromium` (API + web
servers running).

**Result: 6 passed** (chromium project).

- Login and dashboard KPIs render.
- Investigation workspace opens with evidence-by-kind.
- Run Investigation produces agent output (coordinator workflow).
- Mode indicator shows DEMO.
- Provider connectivity test is truthful.
- **All 20 module routes load** (each renders its heading).

Responsive projects (`tablet`, `mobile`) are configured in
`playwright.config.ts` and reuse the same specs. They were not run in the build
environment to keep CI time bounded; run them with
`npx playwright test --project=tablet --project=mobile`.

## Skipped / not executed (with reasons)

| Item | Reason |
|------|--------|
| Real vendor connector tests (Splunk, CrowdStrike, etc.) | No real credentials/endpoints available. Adapters + a mock server are provided; **we do not claim any integration was tested against a real vendor.** |
| Real LLM provider calls | No API keys configured. The gateway's real-provider path is implemented; only the simulated path is exercised in tests. |
| Responsive Playwright projects | Configured but not run in-environment (time). |
| Docker image build (`up --build`) | Compose config validated; images not built in the test run (no push target). |
| Load/performance testing | Out of scope for this build. |

## Honesty statement

No test result above is fabricated. Where an external system was unavailable, the
corresponding capability is either simulated (and clearly labelled) or reported
as not-configured — never as a false success. See
[KNOWN_LIMITATIONS](KNOWN_LIMITATIONS.md).
